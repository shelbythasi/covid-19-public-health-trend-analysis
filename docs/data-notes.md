# Data Notes

This project uses COVID-19 datasets provided for coursework in Data Visualization at the University of South Florida.

Two data workflows were used:

- A consolidated dataset containing daily COVID-19 case counts and moving averages for Hillsborough, Pinellas, and Pasco counties.
- Florida COVID-19 case records from 2020 and 2021 used to recreate daily case trends and county-level comparisons.

The original course-provided datasets are not included in this repository. The repository contains selected analysis code and visualizations for portfolio presentation.
